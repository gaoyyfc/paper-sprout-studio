# 产品案例：让生成式儿童视频可控、可改、可恢复

## 用户问题

一次性生成整条视频看似方便，但只要一个分镜、角色动作或配音不满意，往往需要整体重做，成本高且结果不可预测。

## 产品目标

把视频生成拆成可观察的节点，让创作者能够确认中间结果、局部编辑、单点重生成，并在刷新或中断后恢复项目。

## 核心方案

- 节点画布呈现 IP、文案、分镜、素材、配音、预览和导出状态。
- 分镜数量可变，每个分镜独立新增、删除、排序和重生成。
- 背景和角色分层生成，角色经纯色背景抠图得到透明 PNG。
- 项目数据与素材按项目 ID 隔离。
- Remotion Player 实时预览，Renderer 在后台异步导出。

## 关键产品决策

1. **Human-in-the-loop**：模型生成后不自动一路执行，关键节点允许人工确认。
2. **局部重生成**：保留满意结果，只替换失败节点。
3. **显式状态机**：前端显示等待、运行、成功、失败与暂停状态。
4. **自动化质量门槛**：用脚本覆盖暂停恢复、重生成、透明通道和渲染抽帧。

## 取舍与风险

- 节点化增加界面复杂度，但换来更低的返工成本和更强可解释性。
- 自动抠图对输入背景和边缘质量敏感，需要人工预览兜底。
- 儿童内容仍需人工审核事实、语言、画面安全和版权。

## 我的职责

独立完成产品流程、节点交互、分镜/素材模型、生成服务、角色抠图、实时预览、后台渲染和端到端 QA。
