# 指标与验证计划

| 指标 | 目标问题 | 采集方式 |
|---|---|---|
| 首条可预览时间 | 用户多久看到第一版 | 前后端阶段时间戳 |
| 单镜重生成成功率 | 局部修改是否可靠 | 重生成任务日志 |
| 中断恢复成功率 | 刷新后是否继续工作 | 自动化场景测试 |
| Alpha 合格率 | 角色边缘是否可用 | 棋盘格预览 + 人工抽检 |
| 视频导出成功率 | 完整交付是否稳定 | 渲染任务结果 |
| 单条生成成本 | 方案是否经济可持续 | 模型调用账单汇总 |

当前仓库保存了 UI、透明通道和抽帧 QA 证据，但尚未声明未经稳定样本验证的业务提升比例。
